# Hardware

Schematics, BOM, wiring and safety notes, planned for Milestone 4.

- **First prototype:** an AD8232 single-lead front end, read by the ADC of an ESP32-S3 board, battery-powered.
- **Later, after Milestone 6:** an ADS1293 front end with a register-level SPI driver, still used as a single lead (OP-042).
- **Licence:** the licence of the hardware files is still to be decided (OP-001).

⚡ The device must run only on battery power while electrodes are attached to a person. Never connect it to USB, a charger, or mains-powered equipment while it is worn.
