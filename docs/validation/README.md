# Validation reports

Generated evaluation reports (EC57-style Se / +P for QRS detection, beat classification, HRV) are written here by the validation pipeline in `dsp/scripts/`. Do not edit generated files by hand.

| Report | Requirements | Regenerated by |
|---|---|---|
| [`qrs-ec57-report.md`](qrs-ec57-report.md): QRS detection on the MIT-BIH Arrhythmia Database (EC57 beat-by-beat scoring) and on the Noise Stress Test Database | SRS-007, SRS-009, SRS-012, SRS-014 | `uv run python scripts/validate.py` (from `dsp/`, with the databases downloaded by `scripts/download_data.py`) |

A report states the software and the data it was produced from. It is regenerated whenever the code that produces it changes, and at each milestone release (`docs/regulatory/sdp.md`).
